# 🚀 Retail Pulse Prediction
### AI-Powered Retail Sales Forecasting & Insights

## 🧠 Overview

Retail Pulse is an AI-powered system that predicts which products are likely to run out of stock using historical sales data.

It helps businesses take proactive decisions instead of reacting after inventory runs out.

---

## 🎯 Problem Statement

Predict stock-outs by identifying products likely to run out of inventory using past sales and stock data.

---

## ⚙️ Features

* 📊 CSV Upload (Bulk Prediction)
* 🤖 Machine Learning Model (.pkl support ready)
* ⚡ Automatic Stock-Out Prediction
* 📈 Dynamic Charts (Risk Distribution & Trends)
* 📋 Product-wise Risk Table
* 🎨 Interactive Dashboard UI

---

## 🧠 ML Model

* Algorithm: Random Forest
* Features:

  * Sales
  * Stock
  * Avg Sales (7 days)
* Output:

  * 0 → Safe
  * 1 → High Risk

---

## 📊 Business Logic

* Calculate demand trend using rolling average
* Estimate future stock behavior
* Identify high-risk products
